# PRODIGY_DS_03

## Decision Tree Classifier - Bank Marketing Dataset

This project is part of the ProDigy InfoTech Data Science Internship.

## Objective

Build a Decision Tree Classifier to predict whether a customer will purchase a product or service based on demographic and behavioral data.

## Dataset Used

Bank Marketing Dataset

Source:
https://archive.ics.uci.edu/dataset/222/bank+marketing

- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Workflow

- Data loading
- Data preprocessing
- Label encoding
- Train-test split
- Decision Tree training
- Prediction & accuracy evaluation
- Confusion matrix visualization
- Decision tree visualization
